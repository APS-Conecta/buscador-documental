# FRD: S1 Walking skeleton and permission canary (path: full)

## Goal
Schema (ADR-0002) with migrations and a minimal synchronous principal writer; worker contract v1 (OpenAPI) with contract tests; one scanned PDF -> worker -> OCR -> chunk -> Postgres -> `retrieve()` with live recheck. Design and measure the recheck so that A-PERF-3 (50 hits p95 < 300 ms) is met or a justified waiver is proposed.

## Users
- Searcher A (may read the file), searcher B (may not): the canary actors.
- Admin: sets `rag-excluded`, revokes shares.

## Constraints
- Postgres 17/18 + pgvector 0.8.7; keyword SQL pre-limit 10 000 newest ACL-passing matches; vector leg settings per handoff.
- The Postgres engine stays (ADR-0001 conditionally confirmed).
- ACL principals per file; live recheck is authoritative (ADR-0003). Full `acl_dirty` machinery is S3, not S1.
- Everything runs in Docker with `bd-` compose projects, bound to localhost; no PHP/Tesseract on the host.
- Harness reuse: `spikes/s0-harness/seed/seed_f3_bulk.*`, `bench/m9_isreadable.php`.
