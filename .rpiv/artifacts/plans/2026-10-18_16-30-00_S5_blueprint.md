# S5 blueprint: backfill and operations (checkpoints answered 2026-10-18: interfaces accepted as proposed, data changes accepted as proposed)

## Design
- **Controls live in Postgres, enforced where work is handed out.** `claim_job` (schema 4, `006_s5.sql`) reads `settings`: pause (as now), `work_window` + `work_tz` + `work_window_lanes` (`vec` by default, or `all`), and `cap_text`/`cap_vec` (per-worker concurrency; the global caps stay four times the per-worker cap for text and twice for vec). Defaults reproduce today's behaviour exactly: no window, caps 4 and 2. Freshness is unaffected by the default window lanes: text indexing of new and edited files keeps running by day; only the heavy embedding lane waits for the night.
- **`worker_seen(worker, lane, at, version)`** is upserted by `claim_job` for the calling worker so `doctor` can say whether a worker is alive.
- **ETA** = remaining work divided by the observed rate. Remaining per lane: queued plus claimed jobs; for the whole backfill also in-scope files not yet indexed. Rate: files completed in the last hour (text: `file_state.updated_at` of rows turned `indexed`; vec: files with `vec_state = 'embedded'`), smoothed with the previous hour. Stated margin: within +-30 % when the rate is steady; no ETA (shown as unknown) with fewer than 10 completions in the window or when paused or outside the window (then it says when the window opens).
- **`doctor`** checks, each `ok|warn|fail` with a code and no secret or text: schema version, database roles and extensions, worker secret set and long enough, worker alive (worker_seen within 10 minutes while jobs wait), queue not stuck (oldest queued job age), outbox parked rows, permission backlog age, last reconciliation age, pause state, background-job mode is cron, embedding endpoint reachable and model digest unchanged (only if a profile exists), HNSW index present for ready and active generations, vector failures, disk is not read from SQL so `database size` is reported only. Exit code 1 on any `fail`; `--json` for monitoring.
- **`rotate-secret`** writes a new 48-character secret to `worker_secret`, moves the old one to `worker_secret_prev` with an expiry (`--grace` hours, default 24), and `WorkerAuth` accepts either until the expiry. The new value goes to a 0600 file (`--to-file`) or, without it, is printed once. Rotating again replaces `prev`.
- **Egress.** Compose gets a `workers` network with `internal: true` carrying the worker, db, Nextcloud and the embedding stub; db and Nextcloud stay on the default network for the published loopback ports. The worker has no route to the internet. A test asserts it, and a static test asserts `EmbedClient` is the only PHP class that makes outbound HTTP calls. A remote Ollama is the one deliberate exception and is the administrator's network decision (documented).
- **Backup and restore.** `tools/backup.sh` runs `pg_dump -Fc -n aps_search` (page text included), encrypts it with AES-256-CBC + PBKDF2 (openssl, key from a file), and prints the size and time. `tools/restore.sh` checks the target has the roles and extensions, decrypts, restores with `pg_restore`, and re-runs counts. `tests/e2e/restore.sh` rehearses it on the live stack into a scratch database, proves the restored index answers a search, and records the elapsed time; the measured rebuild time (reindex from scratch of the test corpus) goes to the capacity sheet.
- **Alerts.** `status --prometheus` prints text-format gauges (counts and ages only); `ops/alerts.yml` holds Prometheus-style rules for the situations above; a test parses the file and checks every metric it references exists in the output.
- **Runbooks** (Spanish, administrator page): install, upgrade, rollback, rebuild, restore, rotate the secret, change the profile, night window.

## Failure modes -> tests
| Failure | Test |
|---|---|
| Window set: vec claims refused outside, allowed inside, text unaffected unless lanes=all; pause wins over the window; bad window refused | `S5ClaimTest` (DB) |
| Caps lowered by settings are honoured; junk values fall back to defaults | `S5ClaimTest` |
| ETA from synthetic completions within the stated margin; unknown when the sample is thin, paused, or outside the window | `EtaTest` (unit) + DB |
| Pause, restart of worker/Nextcloud/db, resume: queue intact, work continues | `tests/e2e/ops.sh` |
| Doctor flags each broken precondition (no secret, dead worker, parked outbox, old reconcile, drifted model, missing index) and stays silent on a healthy system | `DoctorTest` (unit/DB) + `ops.sh` |
| Rotation: old secret valid inside the grace, rejected after, new one valid at once; the secret never reaches a log | `WorkerAuthRotationTest`, `ops.sh` |
| Worker cannot reach the internet but still indexes | `tests/e2e/egress.sh` |
| Backup contains page text and is unreadable without the key; restore into a scratch database reproduces counts and a search | `tests/e2e/restore.sh` |
| Alert rules reference only real metrics | `AlertRulesTest` |
