## Phase 3: Corpus generators with self-checks [x] done 2026-10-16 (434 files / 6003 pages, 3.1 GB; F1 reads 7 files = 1.6 %; narrow files stratified every 64th file)
Write-set: `corpus/gen_corpus.py`, `corpus/gen_vectors.py`, `corpus/gen_gold.py`, `corpus/selfcheck.py`, `corpus/determinism_check.sh`.
Steps:
1. gen_corpus: Zipf Spanish vocabulary from a public corpus, Artículo/Capítulo structure; kinds: native, scanned, photographed (skew/noise/rotation), mixed, fake text layer (visible and invisible). Functional scale ~5-10k pages.
2. gen_vectors: random halfvec(384) for the 1M-page-equivalent (~3M chunks), chunk text synthetic, `file_acl.principals` matching F1/F2 membership and group sizes.
3. gen_gold: 200 queries incl. head terms, single-user and 200-group-admin cases.
Success criteria:
- `bash corpus/determinism_check.sh` exits 0 (same seed twice into two scratch dirs gives identical sorted sha256 lists; script added to the write-set)
- `python3 corpus/selfcheck.py` exits 0: every gold query has >= 1 relevant doc readable by its intended user; kind mix matches the spec
Acceptance: A-PERF-1, A-QUAL-3.
