# S2 blueprint: extraction, OCR, chunking

Docker only, compose project `bd-s1` (S2 reuses the harness), 127.0.0.1 only, `make clean` touches only `bd-s1`. Test first: each phase starts with the failing tests, then the code. Commits are local per phase, branch `s2-extraction`; any push or PR is a human gate. Python tests run in the worker image (`make -C worker test`); the app and DB tests keep their targets.

## Decisions (micro-checkpoints answered 2026-10-17)
| # | Decision | Basis |
|---|---|---|
| 1 | Sandbox = separate `parser` container: `network_mode: none`, read-only rootfs, tmpfs, `cap_drop: [ALL]`, `no-new-privileges`, `pids_limit`, `mem_limit`, non-root, no secrets. The supervisor `worker` keeps DB, HMAC and network and never parses. | Tested 2026-10-17: `unshare -n` and `unshare -rn` fail ("Operation not permitted") in the default-seccomp worker container; the hardened container runs, cannot resolve `db` and sees no `BD_DB_DSN`. |
| 2 | OCR pipeline C: ocrmypdf for text; per-page classification `native` / `image-only` / `untrusted layer`; Tesseract TSV for confidence on OCR'd and suspicious pages only. | Cheapest; `native` pages keep `ocr_conf = NULL` and `source = 'layer'`. |
| 3 | Extractors: in-house zip+XML for docx/pptx/odt, openpyxl read-only + defusedxml for xlsx, pypdf + pikepdf for PDF, charset-normalizer for txt/md. No PyMuPDF. | Byte caps under our control; licences compatible with AGPL. |
| 4 | New skip reason `unsafe` (zip/pixel bombs, sandbox violations) in `fail_job`. `corrupt` for unparseable files. | Audit and admin skip list can tell them apart. |
| 5 | PDFs with only an owner password (empty user password) are read. User-password PDFs are skipped `encrypted`. | Readable by anyone; skip when a password is needed. |
| 6 | Tokenizer: count words x 1.3 (documented approximation); the real tokenizer arrives with the embedding profile in S4. Chunk target 300-400, hard max 500, overlap 10-15 % within a section only; tables chunk by row group. | `01-architecture.md:64`, PLAN S2 |
| 7 | `make -C worker eval-ocr` regenerates truth from the S0 manifest `page_text` (not committed); `ocr_ver` and `chunker_ver` embed policy name and flags so any change reprocesses through the idempotency key. | ADR-0005 copy-on-hit key |
