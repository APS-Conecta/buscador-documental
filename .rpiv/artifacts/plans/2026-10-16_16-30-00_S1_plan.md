# S1 plan: walking skeleton and permission canary

Source of truth: the accepted design, sections 0-9 plus section 10 (review conditions) and section 11 (H1, H2, M2, M4, M5, M6), all binding. Paths are relative to `/root/buscador-documental`; the app lives in `app/` (`OCA\BuscadorDocumental`), harness reuse from `spikes/s0-harness/`. Compose project `bd-s1`, 127.0.0.1 only, `make clean` touches only `bd-s1`. Never kill processes by pattern; nothing runs on the host outside Docker. 2. `db/init/00-roles.sql` (admin init script, not the NC user): create `NOLOGIN bd_owner` (privileges only on `aps_search`), `bd_worker` (login, no table privileges), `CREATE EXTENSION unaccent`; grant NC DB user CREATE on the database (documented admin step, D2). `vector` created here for S4, not used in S1.
3. Raw-SQL migration step (`IDBConnection`) loading `sql/001_schema.sql`, `002_functions.sql`, `003_roles.sql`: S1 tables of design section 2 only, `spanish_unaccent` config + `schema_meta(schema_ver, ts_config_ver)`; fail with a message naming the admin step when CREATE or extension privilege is missing. Down migration refuses when `file_state` has rows unless forced (D2).
4. SECURITY DEFINER functions owned by `bd_owner`, `search_path = aps_search, pg_catalog, pg_temp`, `REVOKE ALL FROM PUBLIC`, `EXECUTE` to `bd_worker` only: `claim_job` (n <= 4, bumps `lease_epoch`, `clock_timestamp()` for leases), `heartbeat`, `write_result` (forces `file_id` from the job row; epoch, lease, etag, hash, size caps <= 2000 chunks / 20 000 chars; refuses when job row missing -> `stale_lease`, or `text_state='skipped'`), `fail_job` (reason enum, L-carry). H2: every function starts with `SELECT ... FROM job WHERE id=$1 FOR UPDATE`; erase locks by `file_id`.
5. `IndexEraser::erase(fileId, reason)` per H1: one transaction, same lock as H2, deletes `page`, `chunk`, `file_acl`, `file_meta`, deletes the file's `job` rows, sets `file_state` skipped(reason).
6. `PrincipalWriter::write(fileId)` (owner `u:`, user shares `u:`, group shares and groupfolder groups `g:`, bumps `acl_ver`) and `PrincipalResolver` (uid -> `u:`, `g:*`, `x:recheck`). `FileIndexer::enqueue` writes `file_state`/`file_meta`/`file_acl`/`job` rows and refuses already-excluded files (D4). `STUB(S3)` markers name the S3 ticket for the tag listener (create/locate the ticket id; if none exists use `S3-listener-rag-excluded` and record it in the handoff).
7. A-SEC-4 DB test (as `bd_worker`): INSERT/UPDATE/DELETE/SELECT on every table and on `schema_meta` fails (wider privilege test, L-carry); only the four functions execute; foreign `file_id` in payload ignored; zombie epoch -> `stale_lease`; wrong etag/hash rejected; H1 test (claim, erase, `write_result` -> zero rows); H2 test: two concurrent sessions (stale `write_result` vs `claim_job`).

## Phase 2 (U2): Worker contract v1, app endpoints, Python worker [ ]
Write-set: `app/openapi/worker-v1.yaml`, `app/appinfo/routes.php`, `app/lib/Controller/WorkerController.php`, `app/lib/Security/WorkerAuth.php`, `app/tests/unit/Security/*`, `app/tests/contract/*`, `worker/Dockerfile`, `worker/main.py`, `worker/client.py`, `worker/ocr.py`, `worker/chunk.py`, `worker/tests/*`, `compose.yaml` (worker service).
Steps:
1. Hand-write `worker-v1.yaml` (meta, content with `Range`, mandatory `If-Match`, 412/403/429, error bodies without detail) with examples used by both contract suites.
2. `WorkerAuth` middleware: `Authorization: Bearer <worker_id>.<hmac>`; signed string = method, raw path, query string, `Range`, `If-Match`, `worker_id`, sha256(body), timestamp, nonce (D3, M6); window ±120 s; nonce inserted atomically with `IMemcache::add` only after MAC verifies, TTL 5 min; refuse to start without a shared cache in multi-node; fail closed if the cache cannot guarantee TTL; constant-time compare; secret in sensitive `IAppConfig` `worker_secret`. Concurrency derives from active claims in the DB (global active-lease cap, identity from credentials, M1 carry), not an `ICache` counter.
3. `WorkerController` `meta`/`content`: serve only when the caller holds `claimed_by`, current `lease_epoch`, unexpired lease; re-check exclusion before serving bytes (M6); system root read; no paths or owners; encrypted flag in meta. Document TLS or single-host private network requirement.
4. Python worker: `claim_job` -> meta -> content with `If-Match` -> sha256 stream -> `ocrmypdf --sidecar --skip-text --deskew --rotate-pages -l spa+eng` (version recorded) -> `STUB(S2)` blank-line/size chunker -> `write_result`; 412/`stale_lease` abandon silently; encrypted -> `fail_job('encrypted', false)`; `OMP_THREAD_LIMIT=1`; payload byte caps (L-carry). The worker connects as `bd_worker` only.
5. Unit test asserts nonce TTL >= 2x window; tests for bad MAC, replay, stale timestamp, tampered query/Range/If-Match, wrong `claimed_by`, expired lease, excluded file (-> no bytes).
Success criteria:
- `make -C app test-unit` exits 0 (WorkerAuth, controller)
- `make -C app test-contract` exits 0 (PHP controller vs recorded client requests; Python client vs PHP stub; both from `worker-v1.yaml` examples; deliberate drift in the yaml makes it exit non-zero, checked once by hand and noted)
- `make -C worker test` exits 0
- `make -C app test-e2e-one` exits 0: enqueue one scanned PDF, worker reaches `file_state.text_state='indexed'` and `select count(*) from aps_search.chunk where file_id=<id>` > 0
- zombie-worker test: second claim after lease expiry, first worker's `write_result` raises `stale_lease` and row counts unchanged (`make -C app test-db` still exits 0)
Acceptance: A-SEC-4 (channel and zombie), A-SEC-1 (M2 groundwork not touched here).

## Phase 3 (U3): retrieve(), Recheck, exclusion [ ]
Write-set: `app/lib/Search/Retrieve.php`, `app/lib/Search/Recheck.php`, `app/lib/Search/RecheckResult.php`, `app/tests/unit/Search/*`, `app/tests/integration/search/*`.
Steps:
1. `Retrieve::run(uid, query, limit)`: `websearch_to_tsquery('spanish_unaccent', :q)`, `principals && :set` with `x:recheck` always in the caller set, `ORDER BY chunk_id DESC LIMIT 10000` before `ts_rank`, group by `file_id`, over-fetch ~2x with refill, Recheck, `ts_headline` only for final hits with `snippetAllowed`, HTML-escaped; 5 s statement timeout -> explicit "demasiados resultados" result; Postgres down -> clear error, no fallback to unrechecked data.
2. `Recheck::filter(uid, fileIds)`: one `setupFS`/`getUserFolder` per request; per-hit `getById`, best readable node, share expiry and `permissions.download` evaluated; folder memo keyed `(storageId, folderId)`; ancestor walk within the node's storage to its root via `oc_filecache` parent ids for tag lookup only (never `permissions`), with a depth cap; failed or partial walk drops the hit (D1 condition); bulk `getTagIdsForObjects`; resolve every system tag named `rag-excluded` regardless of flags (M5), error or no tag found -> fail closed + admin warning; exception per hit drops it; tag service down -> whole recheck fails closed; no caching of outcomes across requests (L-carry); drop counter, no content in logs (M4).
3. M2: `snippetAllowed=false` hits return title only: no `heading`, `page_no`, snippet or chunk identity.
4. Unit tests with fakes: expired share, download-disabled (title-only JSON asserted in full), multi-mount, tag on ancestor above the sharee's mount, partial walk -> dropped, duplicate tag, tag service failure -> closed, `x:recheck` unreadable file dropped, readable file missing from `file_acl` = false negative.
5. Verify in NC 34 and record in the validation notes: who may assign public/restricted tags (M5), mount-cache staleness and multi-node download semantics (M3, M7). Findings that break a design assumption stop the phase and go back to `/bd-design`.
Success criteria:
- `make -C app test-unit` exits 0 including `Search/*`
- `make -C app test-search` exits 0 (PG integration: prefilter returns the file id for stale principals, drop counter increments, hit JSON has no `heading`/`page_no`/`snippet` when download is disabled)
- `grep -rn "permissions" app/lib/Search/Recheck.php | grep -v "download" | wc -l` prints 0 (no direct `oc_filecache.permissions` read)
Acceptance: A-SEC-1 (subset), A-SEC-2, A-SEC-3.
