## 2. Data changes (schema `aps_search`; expand/contract; worker refuses unknown `schema_ver`)
S1 tables only; `chunk_vec_<gen>`, `embedding_profile`, `outbox`, `tombstone`, `audit_log` arrive in S3/S4.
- `schema_meta(schema_ver int, ts_config_ver int)`.
- `file_state(file_id bigint pk, etag text, content_hash text, text_state text, vec_state text default 'pending', acl_dirty bool default false, skip_reason text, ocr_ver text, chunker_ver text, updated_at timestamptz)`; `text_state` check in (`pending, extracting, ocr, chunking, indexed, skipped`). `acl_dirty` exists but is not read in S1.
- `job(id bigserial pk, lane text, file_id bigint, idem_key text unique, lease_until timestamptz, lease_epoch bigint default 0, claimed_by text, claimed_etag text, claimed_hash text, attempts int default 0, not_before timestamptz default now())`; claim via `FOR UPDATE SKIP LOCKED`.
- `page(file_id, page_no, text, ocr_conf real, ocr_ver, source text, pk(file_id,page_no))`.
- `chunk(chunk_id bigserial pk, file_id, page_no, ord, heading, text, tsv tsvector generated always as (to_tsvector('spanish_unaccent', text)) stored, chunker_ver)` + GIN(`tsv`), btree(`file_id`).
- `file_meta(file_id pk, name, mime, mtime)` + `pg_trgm` index deferred (S4 filename search).
- `file_acl(file_id pk, principals text[], acl_ver int)` + GIN(`principals`).
- `unaccent` extension + `spanish_unaccent` config in a versioned step (`ts_config_ver`).

Roles: `bd_app` (the NC DB user; full DML in schema) and `bd_worker` (no table privileges; `EXECUTE` on the four functions only; `SET search_path` pinned in each function).
Functions (all `SECURITY DEFINER`, `search_path = aps_search, pg_catalog`, `REVOKE ALL FROM PUBLIC`):
- `claim_job(lane text, n int, worker text) -> setof (job_id, lease_epoch, file_id, etag)`: picks due jobs, bumps `lease_epoch`, sets `lease_until = now()+lease`, records `claimed_etag` from `file_state`.
- `heartbeat(job_id, lease_epoch) -> bool`.
- `write_result(job_id, lease_epoch, etag, content_hash, pages jsonb, chunks jsonb) -> void`: in one transaction: verify `job.lease_epoch = $2 and lease_until > now()` (else raise `stale_lease`), verify `etag = claimed_etag` and, if `claimed_hash` is set, equality of `content_hash` (else `hash_mismatch`); delete then insert `page`/`chunk` **forcing `file_id` from the job row** (the payload has no `file_id`), set `file_state` to `indexed`, delete the job.
- `fail_job(job_id, lease_epoch, reason text, retryable bool)`: backoff `not_before`, or set `skipped(reason)`.

## 3. Principal writer (S1 minimal)
`PrincipalWriter::write(int $fileId)`: owner `u:<uid>`; direct user shares `u:<uid>`; group shares and groupfolder group permissions `g:<gid>`; `acl_ver` bumped. Called synchronously by `FileIndexer::enqueue`. Anything not modelled (groupfolder advanced ACL/deny, circles, Talk/Deck) is covered by the caller always carrying `x:recheck` and the file carrying `x:recheck`-class marker only in S3; in S1 `file_acl` rows are a prefilter and the recheck is the authority. Prefilter staleness gives false negatives only (ADR-0003). No `acl_dirty` processing (`STUB(S3)`).

## 4. Worker contract v1 (fixes ADR-0007 open values; `openapi/worker-v1.yaml`)
- HTTP: `GET /apps/buscador_documental/worker/v1/files/{id}/meta` -> `{file_id, etag, size, mime, name, mtime, encrypted:boolean}`; `.../content` (200/206, `Range`, **`If-Match: <etag>` mandatory**, 412 on change, 403 when no active claim, 429 above concurrency cap). Serves only files with an active claim for the calling worker; reads as system root; never returns paths or owners.
- Auth: `Authorization: Bearer <worker_id>.<hmac>` where hmac = HMAC-SHA256(secret, `method \n path \n sha256(body) \n unix_ts \n nonce`), headers `X-BD-Timestamp`, `X-BD-Nonce`. **Proposed values:** timestamp window ±120 s; nonce replay cache in `ICache` (distributed if configured) for 5 min; per-worker concurrency cap 4; secret in sensitive `IAppConfig` (`worker_secret`), rotation via `occ` is S5 (S1: set by test setup). Constant-time compare.
- DB side per section 2. Payload shapes: `pages: [{page_no, text, ocr_conf, source}]`, `chunks: [{page_no, ord, heading, text}]` (no `file_id`, no principals, bounded by size caps checked in `write_result`: <= 2000 chunks, text <= 20 000 chars).
- Contract tests: Python client against a PHP stub server **and** PHP controller against recorded client requests, both generated from `worker-v1.yaml` examples; schema-drift fails CI.
- Worker loop (Python): `claim_job` -> `GET meta` -> `GET content` with `If-Match` -> sha256 the stream -> `ocrmypdf --sidecar --skip-text --deskew --rotate-pages -l spa+eng` (version pinned and recorded) -> `STUB(S2)` placeholder chunker (blank-line/size split, heading none) -> `write_result`; on 412 or `stale_lease` abandon silently; encrypted -> `fail_job('encrypted', false)`. One process, `OMP_THREAD_LIMIT=1`.

## 5. Recheck design (open item #11, A-PERF-3)
Semantics (must equal `getById` semantics, ADR-0003 + architecture §3.4): the user has at least one readable node for the file id (any readable mount counts); share not expired; `permissions.download` share attribute not false (otherwise title only, no snippet); file not excluded by `rag-excluded` on the file or any ancestor. Never read `oc_filecache.permissions` directly (bypasses groupfolder ACL and shares).

`Recheck::filter(string $uid, int[] $fileIds): RecheckResult[]` (`{fileId, node, snippetAllowed}`), one instance per request, with these levers, each measured separately in U4:
1. **One FS setup per request**: `setupFS` + `getUserFolder` once (S0: setup alone is ~100-160 ms; keep it out of the per-hit path, and report it apart from the per-hit cost).
2. **Per-hit `getById`** (kept for correctness); take the best readable node, evaluate share expiry/download attribute from the node's mount/share (the corrected probe enforces them).
3. **Folder memo**: `(storageId, folderId) -> excluded?` so hits clustered in the same folders walk ancestors once; ancestors walked within the node's **storage** up to its root, not only up to the viewer's mount root, because exclusion is the owner's decision and must hold for sharees (decision D1 below).
4. **Bulk tag lookup**: collect the unique file and ancestor ids from levers 2-3 and make one `ISystemTagObjectMapper::getTagIdsForObjects($ids, 'files')` call (one chunked `IN`), then test for the `rag-excluded` tag id (resolved once per request via `ISystemTagManager`). Replaces S0's per-ancestor `haveTag`.
5. **Candidate trim**: `retrieve()` rechecks the top documents only (over-fetch ~2x the page, refill if short), never all 10 000 candidates.
6. Variant to test, not assumed: `Folder::search(SearchQuery)` constrained to the candidate ids (core `FilesSearchProvider` approach, no recheck call per id). Adopted only if it preserves semantics 1-4 and beats the memo variant.
Failures drop the hit silently; nothing from a dropped hit is logged.

Decision rule (U4): corrected-probe p95 for 50 hits on the F3-style fixture across >= 3 users x 30 reps in a quiet box. If p95 (check time, setup reported separately) < 300 ms: A-PERF-3 met, record in `capacity-sheet.md`. If setup is the only overage: propose per-request budget ADR (setup counted once per search, not per hit). If still > 300 ms: waiver ADR with the measured number, and `02-performance.md` budget reconciled; never loosen the semantics to hit the number.

## 6. `retrieve()` and exclusion
`Retrieve::run(uid, query, limit)`: principals (`PrincipalResolver`) -> SQL: `websearch_to_tsquery('spanish_unaccent', :q)`, `file_acl.principals && :principals` **with `x:recheck` always in the caller set**, newest-10 000 candidate pre-limit (`ORDER BY chunk_id DESC LIMIT 10000` before `ts_rank`, ADR-0001 outcome), group by `file_id`, best chunk -> `Recheck` -> `ts_headline` snippet only for final hits and only if `snippetAllowed`, HTML-escaped. Per-request statement timeout (default 5 s) with an explicit "demasiados resultados" error result for S4's UI. Exacta only; relaxation to OR, synonyms, filters, modes, paging are S4.
`IndexEraser::erase(fileId, reason)`: one transaction deleting `page`, `chunk` rows and `file_acl`, set `file_state.text_state = 'skipped'`, `skip_reason = reason`; cancels pending jobs for the file.

## 7. Failure modes
| Failure | Behaviour |
|---|---|
| Worker dies after claim | lease expires; next `claim_job` bumps `lease_epoch`; old worker's `write_result` raises `stale_lease` (A-SEC-4) |
| File changed during OCR | `If-Match` 412 or `etag` mismatch in `write_result`; job re-queued with new etag |
| Content differs from claimed hash | `hash_mismatch`, no rows written, attempt counted |
| Bad HMAC / replay / stale timestamp | 401, no body detail, counted in logs without payload |
| Postgres down at search | clear error result, no partial hits, no fallback to unrecheck data |
| NC DB user lacks CREATE/extension privilege | migration aborts before any table, message names the admin step (C2) |
| `unaccent`/ts config version mismatch | worker refuses (schema_ver / ts_config_ver) |
| Recheck exception for one hit | hit dropped (fail closed) |
| Tag service unavailable | whole recheck fails closed (no results), error logged without content |

## 8. Test strategy (maps to acceptance)
- Unit (PHPUnit): `PrincipalResolver`, `PrincipalWriter` (owner, user share, group share), `WorkerAuth` (window, replay, bad mac), `Recheck` with fakes (expired share, download-disabled, multi-mount, tag on ancestor, tag service failure -> closed).
- DB tests (integration, PG): **A-SEC-4**: as `bd_worker` INSERT/UPDATE/DELETE/SELECT on every table fails; `write_result` with a foreign `file_id` in payload is ignored (rows land on the claimed file); zombie worker with old `lease_epoch` raises `stale_lease` and changes nothing; wrong etag/hash rejected.
- Contract tests: client and server against `worker-v1.yaml`.
- Canary (`make test-canary`, compose job; seeds from the S0 `seed_nc.sh` pattern, new bd-s1 project): one scanned PDF owned by A (and shared to nobody) -> worker -> `indexed`:
  1. A finds it (**A-SEC-1** baseline); B does not.
  2. A shares to B: B finds it; A revokes the share **without** touching `file_acl`: hit absent (**A-SEC-2**, stale prefilter).
  3. Tag file `rag-excluded`: hit absent immediately; `IndexEraser::erase` then `count(*) = 0` on `page`/`chunk` for the file (**A-SEC-3**); same with the tag on the parent folder.
  4. Download-disabled share: hit present, snippet null (part of A-SEC-1 matrix; full matrix S3).
- Perf (U4): corrected `m9_isreadable.php` variants V0 naive, V1 +folder memo, V2 +bulk tags, V3 search-constrained; fixture `seed_f3_bulk` (25/10/5/10) extended with expired share and multi-mount; 30 reps x 3 users, JSON in `results-s1/`, summarised into `capacity-sheet.md` (**A-PERF-3**).
- Out: real OCR quality (S2), hostile files (S2), full RBAC matrix, circles, deleted user, moved file (S3).

## 9. Decisions requested at design-review
- D1: exclusion tag evaluated on ancestors across the storage root (owner's tree), not only up to the viewer's mount. Costs more per hit; safer for sharees.
- D2: raw-SQL migrations in schema `aps_search` (C2) and the install-time DB privilege step.
- D3: HMAC window ±120 s, nonce cache 5 min, concurrency cap 4 per worker.
- D4: `IndexEraser` is called manually in S1; the tag listener waits for S3 (C9).
- D5: stale ADR text fixes (C1, C3, C4, C5, C6) applied in the U1 commit.
- D6: Postgres 18 image (`pgvector:0.8.7-pg18-bookworm`, data mounted at `/var/lib/postgresql`) for S1 to match siblings; S0 numbers were on 17.11.

Acceptance covered: A-SEC-1 (baseline subset), A-SEC-2, A-SEC-3, A-SEC-4, A-PERF-3.

## 11. Amendments from the adversarial ACL review (user-approved 2026-10-16, binding)
Source: bd-acl-adversary review, claims checked against this design. Each amendment names the section it changes.
- **H1 (sections 2, 6, 8; A-SEC-3):** `IndexEraser::erase` also deletes the file's `job` rows (or bumps `lease_epoch`), deletes `file_meta`, and runs under the same row lock as H2. `write_result` raises `stale_lease` when the job row is missing and refuses to write when `file_state.text_state = 'skipped'`. Section 6 and C9 are unified: erase deletes `page`, `chunk`, `file_acl`, `file_meta`, cancels jobs, sets `skipped(reason)`. Test: claim, erase, `write_result` -> zero `page`/`chunk` rows.
- **H2 (section 2; A-SEC-4):** `write_result`, `claim_job`, `heartbeat`, `fail_job` and `erase` all start with `SELECT ... FROM job WHERE id = $1 FOR UPDATE` (erase locks by `file_id`) before comparing `lease_epoch`; lease expiry is compared with `clock_timestamp()`, not `now()`. Test: two concurrent sessions (stale `write_result` vs `claim_job`), in addition to the sequential zombie test.
- **M2 (sections 5, 6, 8; A-SEC-1):** hits with `snippetAllowed = false` return the file title only: no `heading`, `page_no`, snippet or matched-chunk identity. The canary asserts the full hit JSON, not just `snippet == null`. The remaining match oracle (a user can probe words in a download-disabled file) is recorded as an accepted risk in an ADR written with the plan.
- **M4 (section 8; A-SEC-2):** the canary asserts that stale `file_acl.principals` still contains `u:B` at query time, that the SQL stage returned the file id, and that the recheck dropped it (drop counter, no content logged). Negative controls: an unreadable `x:recheck` file is dropped; a readable file missing from `file_acl` is a false negative, not a leak.
- **M5 (sections 5, 7, 8; A-SEC-3):** the recheck resolves every system tag named `rag-excluded` regardless of flags and treats any of them as exclusion. If tag resolution errors or finds no such tag, the recheck fails closed and logs an admin warning. Setup creates the tag as restricted/admin-assignable. Canary case: duplicate tag. Who may assign public tags in NC 34 is to be verified in U3.
- **M6 (sections 4, 7, 8; A-SEC-4 channel):** the nonce is inserted atomically (`IMemcache::add`) only after the MAC verifies; the signed string includes `worker_id` and the raw path. The cache must not evict inside the TTL, otherwise the channel fails closed. `meta` and `content` verify `claimed_by`, the current `lease_epoch`, an unexpired lease, and re-check exclusion before serving bytes. TLS or a single-host private network is required and documented.

Carried to the plan as tasks or tests (not binding amendments yet): M1 (global active-lease cap, identity from credentials), M3 and M7 (verify mount-cache staleness and multi-node download semantics in NC 34, add a group-removed canary), L1-L11 (`pg_catalog` first in `search_path`, wider A-SEC-4 privilege test, `fail_job` reason enum, payload byte caps, no caching of recheck outcomes, `log_statement=none` in the S1 compose, ancestor-walk depth cap, doc wording of `x:recheck`).
