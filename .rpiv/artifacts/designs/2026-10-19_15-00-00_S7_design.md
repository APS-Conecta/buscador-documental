# S7 design: hardening and release

Decisions already taken by the user: licence AGPL-3.0-or-later (add `LICENSE` and `THIRD-PARTY-NOTICES.md`); the load test and the restore rehearsal run here in their own throwaway `bd-s7` compose project (localhost only, `bd-` prefix, removed afterwards). Everything else below is proposed.

## 1. STRIDE review of the worker channel and the database role (A-SEC-8)
Artifact `buscador/stride-worker-channel.md`: one table per element (HMAC channel Nextcloud<->worker, `bd_worker` role and its SECURITY DEFINER functions, parser sandbox, Ollama endpoint, admin endpoints, backup files), each threat with its control and the test that proves it, or a gap. Gaps rated high are fixed test-first in this slice; none may stay open (exit criterion). The `folder_id` probe (S6 review) is fixed here (restrict to readable indexed folders).

## 2. Failure-mode tests (architecture section 9)
Eleven modes, each mapped to an existing test or a new live suite `test-e2e-failures`: Postgres read-only/full, worker dead (doctor/alert), lease expiry mid-job, etag changed during fetch, query-embedder down (fallback with notice), HNSW build in progress, `acl_dirty` backlog (doctor warning), malicious/zip-bomb/encrypted files, model digest mismatch, HMAC clock skew, restore from a backup with a newer schema (refused). The table in the artifact says which exist (most do from S1-S5).

## 3. Load test at 1M-page equivalent (A-PERF-1/2/5, A-QUAL-3)
`spikes/s7/`: set-based generator fills the real `aps_search` schema (1M pages, ~3M chunks, vectors for the active profile, ACL principals for 200 groups) in `bd-s7`; a PHP driver in the test image runs the real `CandidateQuery`/`Searcher` SQL stage (recheck is a separate, already-measured cost, ADR-0010) for 1/5/10/20 concurrent searchers and page sizes 25/50/100, reports p50/p95/p99 for Exacta and Mixta, and filtered recall for a narrow user versus a 200-group admin (A-QUAL-3, within 5 points). Results in `spikes/s7/results-s7/`; thresholds are the `[M0]` numbers. A miss is either fixed (index/query) or waived by an ADR with the number.

## 4. Restore rehearsal at scale (A-OPS-2)
`tools/backup.sh` / `restore.sh` on the 1M-page database: measured backup time, size, restore time and time to first correct search, written to `spikes/s7/results-s7/restore_at_scale.json` and the capacity sheet.

## 5. Release tarball and clean install (A-OPS-5)
`make -C app release` builds `dist/buscador_documental-<version>.tar.gz` from tracked files only (no tests, harness, node_modules, sources of the bundle; includes `js/`, `css/`, `appinfo`, `lib`, `templates`, `img`, `openapi`, licence) plus a `.sha256`. `make -C app test-e2e-install` starts a clean Nextcloud 34 (no volume mounts of the repo), extracts the tarball into `custom_apps`, enables the app, runs `occ buscador:doctor`, adds a folder, indexes one file with the worker and searches. CI job `install` runs it; job `nc35` runs the same against Nextcloud 35 with `continue-on-error: true` (non-blocking, as planned). Signing for the Nextcloud app store is out of scope (needs the org's certificate: noted as a release step for the owner).

## 6. Legal gate (A-SEC-7)
Cannot be closed by code. ADR-0006 gets a supersession-note section with the exact conditions (counsel opinion on Ley 21.719, DPIA owner, notice text, pause) and a status line "open". `occ` and the admin page keep opt-in scope. The release notes state: no real-data install before the gate is recorded. Acceptance row A-SEC-7 stays "open, external" rather than green.

## 7. Documentation
Final Spanish pages (usuario, administración, desarrollo, novedades with the first version), `glosario`/catalogue updates, then publication to APS-Conecta/documentation following the site's structure (PR; human gate; `repo-docs.py check` and `term-check.py` in a scratch clone).

## 8. Risks
1M-page load generation time and disk (mitigated: set-based SQL, own volume, removed after); NC 35 may fail on API changes (non-blocking by design); tarball install differs from the bind-mounted dev stack (that is the point of the test).

## Exit
All rows green or waived by ADR with the measured number; STRIDE artifact without open high items; tarball install green in CI; legal gate recorded as open with its conditions.
