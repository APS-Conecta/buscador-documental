# S3 design review verdict (human gate, 2026-10-17)

Verdict: **accept**, with these answers recorded verbatim from the AskUserQuestion round:
| Question | Answer |
|---|---|
| Index data of a trashed file | Erase at once |
| Who may apply `rag-excluded` | Public, users can assign |
| Wait for the first-run notice? | "Index automatically" (typed answer) |
| Design | Accept |

Interpretation of "Index automatically" (to be corrected by the user if wrong): the notice does not gate indexing; under `opt_in` indexing starts as soon as a scope rule exists. It is NOT read as "index everything without rules" or as lifting the `all_readable` lock, which ADR-0006 ties to counsel and the DPIA.

Earlier answers that shaped the design: admin-managed rules with automatic subtree and "all team folders" coverage (FRD, 2026-10-17).
Defaults accepted by the design and still flagged for counsel: 30-day tombstone ledger, 90-day audit retention.

Correction recorded after the verdict: when the trash option was presented, "the content-hash cache makes re-reading cheap" was overstated. ADR-0005's dedupe is copy-on-hit from an already-indexed file; a restored file with no other indexed copy is read again in full. The user's answer (erase at once) was given with that statement in front of them; it is kept, and the user is told so explicitly in the next report so it can be reversed.
