# S6 review

Reviewers (general-purpose agents with the `.claude/agents` definitions; claims verified against the code by the author): diff auditor (15 rows), ACL adversary (7 findings, many attacks tried and failed), UX auditor (15 rows).

## Fixed test-first
- Search-bar subline showed raw `<mark>` and escapes: now plain text (`UnifiedSearchProviderTest`).
- `ExclusionUnavailable` made file-text, folder and admin endpoints 500, and killed the admin overview exactly when the doctor is needed: endpoints answer 503; overview needs no recheck (`skippedCounts`).
- File text: pages cut in the database, truncation reported for >1000 pages, policy skip reasons answer "none", uncertain flag per page from the server threshold (`UiServicesTest`).
- `uncertain` leaked a content-derived bit without the snippet: gated on `snippetServable` (`SearcherPgTest`).
- Frontend: search cleared in flight came back; refused admin actions reported success; `?modo=constructor`; `attachShadow` twice; focus lost after search/paging (now moved to the results); status roles on empty/notice states; wrong reason text for disabled meaning modes; ungrammatical reason sentences; unlabeled row buttons; no second warning when meaning search is off; Chilean time zone for dates; `npm ci` in the drift gate; brute-force setting restored by `ui.sh`.
- Pause no longer hides the search-bar provider (what is read stays searchable).

## Rejected
- "formatNumber uses a normal space": the source holds U+00A0 (bytes C2 A0); a test asserts it.

## Accepted and documented
- `page.total` counts snapshot rows before the page recheck (pre-existing, S4 review): a just-revoked or tag-excluded file can inflate the count for minutes; no name or text.
- `folder_id` accepts any id: a sharee can probe ancestor folder ids of files shared with them (ids and nesting only). Fix is small (restrict to `FolderList`); left for S7 hardening with the STRIDE review.
- An administrator sees ids and reason counts of other people's skipped files (names withheld).
- Search-bar queries store a snapshot and share the page's 20-snapshot budget; the provider has no rate limit of its own.
- A re-read blanks snippets of that file for sharees until the worker finishes.
- Not built: numbered pager, collapsible filters on narrow screens, cursor in the URL, arrow-key navigation, "pendiente de lectura" card badge and the permission-filtered empty state (generic "Sin resultados" by design: no existence leak).
