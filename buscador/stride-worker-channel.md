# STRIDE review: worker channel, database role, parser sandbox, embedding endpoint, admin and backup (A-SEC-8)

Slice S7, 2026-10-19. Method: an independent reviewer (general-purpose agent with a security brief, read-only) went through five elements against Spoofing, Tampering, Repudiation, Information disclosure, Denial of service and Elevation of privilege, citing code and tests; the author verified each finding in the code and fixed or dispositioned it. The reviewer ran nothing, so "evidence" below is a test that now exists and passes in the regression run, not the reviewer's word. Elements: (1) HMAC channel worker<->Nextcloud, (2) `bd_worker` role and its SECURITY DEFINER functions, (3) parser container, (4) embedding endpoint client, (5) admin endpoints and backup/restore.

**Result: no open high item.** Eight were reported as high or untested; the table says what happened to each. Everything the reviewer rated low or "control verified" is not repeated here (HMAC coverage of method, path, query, Range and If-Match; nonce store and 120 s window with fail-closed cache; claim binding of job, file, worker, epoch and lease; exclusion check before bytes; range parsing; table privileges of `bd_worker` and the exact list of eight callable functions; fixed `search_path`; payload file id ignored; dynamic SQL uses `%I` on integers only; reason allow-lists; digest, norm and dimension checks of embeddings; redirects refused in PHP; admin routes admin-only with CSRF).

## Controls the reviewer could not verify (open for the install guide, not code defects)
`getRawPathInfo()` behind a rewriting proxy or sub-path install; Nextcloud's brute-force throttle reacting to the worker's `Authorization: Bearer`; a real distributed cache (Redis) with TTL in production (APCu-only fails closed); groupfolder, external storage and server-side-encryption behaviour of the exclusion check; cgroup accounting of the `/work` tmpfs; CVEs of the packages in the worker image (unpinned apt); the production `pg_hba.conf`. The tarball install test (`test-e2e-install`) covers a stock root install only.

## Exit
No high item open; every finding above is fixed with a test or has an explicit disposition. A-SEC-8 is met for this review. The legal gate (A-SEC-7) is separate and stays open (ADR-0006).
